# CTF Radar

Персональный агрегатор CTF-соревнований по **OSINT** и **Steganography** с уведомлениями в Telegram.
Первая версия использует публичный API CTFtime, GitHub Actions для периодического запуска и GitHub Pages для dashboard.

> Важно: у CTFtime обычно нет полного списка категорий будущих заданий. Поэтому Radar ищет категории по названию и описанию события. События без явных ключевых слов могут не попасть в выборку, а совпадение по ключевым словам не гарантирует наличие соответствующего задания. Перед участием проверь официальную страницу события.

## Возможности

- Получение ближайших событий через API CTFtime.
- Фильтрация событий, помеченных как онлайн (`onsite = false`).
- Отбор по ключевым словам OSINT и/или Steganography.
- Дедупликация по ID события и хранение `data/events.json`.
- Telegram-уведомления о новых подходящих событиях.
- Dashboard на GitHub Pages с поиском, фильтрами категорий и статусов.
- GitHub Actions запускает сканирование по расписанию и по кнопке вручную.
- Безопасное хранение Telegram-токена и chat ID в GitHub Secrets.

## Архитектура

1. `src/ctftime.py` получает данные из API CTFtime.
2. `src/radar.py` фильтрует онлайн-события и определяет совпадения по категориям.
3. `src/telegram_notify.py` отправляет уведомления о новых событиях.
4. `data/events.json` публикуется в Pages как статический JSON.
5. `.github/workflows/scan.yml` запускает сканер каждые 6 часов.

## 1. Создать Telegram-бота

1. Открой Telegram и найди `@BotFather`.
2. Выполни `/newbot` и сохрани выданный токен.
3. Напиши своему боту `/start`.
4. Узнай chat ID: открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и посмотри `message.chat.id`.
   - Не публикуй URL с токеном и не добавляй токен в репозиторий.
   - Для группы добавь бота в группу, отправь сообщение и снова проверь `getUpdates`.

## 2. Создать GitHub-репозиторий

Создай новый репозиторий, например `ctf-radar`, и загрузи в него содержимое этого проекта.

В репозитории открой **Settings → Secrets and variables → Actions → New repository secret** и добавь:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather.
- `TELEGRAM_CHAT_ID` — твой chat ID (строка или число).

Не записывай секреты в `config.json`, исходный код или Git.

## 3. Включить GitHub Pages

1. Открой **Settings → Pages**.
2. В разделе **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку `main` и папку `/ (root)`, затем Save.
4. Workflow обновляет `data/events.json` в репозитории; dashboard читает этот JSON.
5. Открой адрес Pages, который покажет GitHub, например `https://USERNAME.github.io/ctf-radar/`.

При первом запуске GitHub Pages может потребоваться несколько минут.

## 4. Запустить сканирование

- Открой вкладку **Actions**.
- Выбери **CTF Radar scan** → **Run workflow**.
- Посмотри логи запуска.
- При успехе workflow обновит `data/events.json` и отправит уведомления о новых совпадениях.

Workflow также запускается автоматически каждые 6 часов. GitHub Actions cron работает в UTC и запуск не гарантируется ровно в указанную минуту. В файле расписание `17 */6 * * *`.

## 5. Настроить окно поиска и ключевые слова

В `config.json`:

- `days_ahead`: сколько дней вперёд запрашивать события (по умолчанию 45).
- `categories`: включённые категории.
- `keywords`: дополнительные ключевые слова для каждой категории.
- `require_online`: оставь `true`, чтобы исключать очные события.
- `notify_on_first_run`: `false` означает, что первый запуск заполнит базу без отправки большого количества старых уведомлений.
- `max_events`: максимальное количество событий, запрашиваемых за один запрос.

Чтобы добавить термин, редактируй `keywords` и сделай commit.

## 6. Локальный запуск (необязательно)

Требуется Python 3.11+.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1

pip install -r requirements.txt
python -m src.radar
```

Для локальных Telegram-уведомлений задай переменные окружения:
- Linux/macOS: `export TELEGRAM_BOT_TOKEN="..."` и `export TELEGRAM_CHAT_ID="..."`
- PowerShell: `$env:TELEGRAM_BOT_TOKEN="..."` и `$env:TELEGRAM_CHAT_ID="..."`

## Источники и ограничения

- Основной источник: [CTFtime API](https://ctftime.org/api/). Используй данные в соответствии с условиями и ограничениями источника.
- В этой версии не скрейпятся сайты, требующие входа, и не обходятся антибот-защиты.
- Фильтрация категорий эвристическая. В будущем можно добавить официальные RSS/ICS/API организаторов и отдельный ручной список источников.
- Статический dashboard публичен, если репозиторий и Pages публичные. Он не содержит Telegram-токена или chat ID.
- Для защиты от повторных сообщений используются сохранённые event ID. Если `data/events.json` удалён или история уведомлений очищена, события могут отправиться повторно.
